# 🌐 My Profile – Personal Website

A modern luxury-style personal website built using **Vite + React + TypeScript**.

---

## ✨ Overview

This project represents a high-end personal portfolio website with a clean architecture and modular component structure.

Built with scalability and maintainability in mind.

---

## 🛠 Tech Stack

- ⚛️ React
- ⚡ Vite
- 🟦 TypeScript
- 🎨 CSS
- 🔥 Supabase (if enabled)

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/alharthalshikh/My-Profile.git
cd My-Profile
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

---

## 🔐 Environment Variables

Create a `.env` file and add:

```
VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
```
